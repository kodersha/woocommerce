# Revit Woo Licenses

## Установка
Скопировать папку в `wp-content/plugins/`, активировать (нужен WooCommerce ≥ 7.0, PHP ≥ 7.4).
Настройки: **WooCommerce → Revit Licenses**. Импорт: **WooCommerce → Импорт версий**.

## Лицензии в личном кабинете
После активации плагин добавляет вкладку **Мои лицензии** в личный кабинет WooCommerce (`/my-account/licenses/`).
В ней отображаются позиции заказов текущего авторизованного покупателя со статусами `processing` и `completed`, если товар отмечен как плагин и для него определён срок лицензии.
Срок рассчитывается по выбранному атрибуту (дни, недели или календарные месяцы), настройке товара либо явному режиму бессрочной лицензии. Для вариативного товара используется атрибут именно купленной вариации.
Данные берутся из WooCommerce Orders API, совместимо с HPOS. Повторный ввод пароля, JWT и отдельная таблица лицензий для витрины не используются. Гостевые заказы не привязываются к аккаунту.

## Формат запроса на сервер (POST, JSON)
Заголовки: `Authorization`/свой заголовок, `X-RWL-Idempotency-Key`, опц. `X-RWL-Timestamp` + `X-RWL-Signature` (`sha256=HMAC(secret, "<timestamp>.<тело>")`).
Ответ 2xx или 409 = принято; 408/429/5xx/сеть = повтор; прочие 4xx = окончательная ошибка.

Плагин (`type: "plugin"`): event, idempotency_key, order_id, plugin_id, name, image, license_start, license_end (ISO 8601 или null для бессрочной лицензии), license_perpetual (true для бессрочной лицензии), user_id, revit_version, product_version.
Файловый товар (`type: "file"`): event, idempotency_key, order_id, product_id, name, image, user_id, revit_version, product_version.
Изменение версии (`event: "version_update"`): plugin_id|product_id, name, image, revit_version, product_version — сервер обновляет записи по товару.

Продление/повторная покупка = новый заказ → новый license_start; сервер должен делать upsert по (user_id, plugin_id).


## Справочник сроков

В настройках **WooCommerce → Revit Licenses** укажите слаг атрибута подписки и значения в формате `значение=единица:число`:

```text
31 день=days:31
Полгода=months:6
1 год=months:12
```

Поддерживаются `days`, `weeks`, `months`. Месяцы считаются календарно, а не как фиксированные 4 недели. Старые записи `значение=число` продолжают интерпретироваться как недели.

Для каждого товара задаётся правило: срок из атрибута, срок по умолчанию или всегда бессрочная лицензия. Для вариативного товара срок берётся из фактически купленной вариации; родительский список значений не используется как замена выбранной вариации.

**Важно:** перед включением отправки бессрочных лицензий необходимо обновить принимающий сервер. Он должен принимать `license_perpetual: true` вместе с `license_end: null`. До этого оставьте флажок поддержки внешним API выключенным — плагин не будет отправлять бессрочную лицензию в несовместимом формате.
